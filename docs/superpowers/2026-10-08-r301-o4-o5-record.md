## O5 — the ledger books ≤ the page's token count on every adopting page

**Where the ledger's figures are exposed (measured).** For an ADOPTED page,
`CompilationReport.asserted`/`.escalated` ARE `adoption.build_ledger`'s own totals, carried
through unchanged (`src/iladub/etkl/compile.py`'s `if adoption == "adopted":` branch:
`asserted_total = _led.asserted_tokens`, `escalated_total = _led.escalated_tokens`; installed
into the document's page list verbatim at `src/iladub/etkl/document.py:1972`,
`pages[p] = rep_a`). So the AFTER snapshot's per-page `asserted + escalated`, for every page
index in a document's `adopted` list, already **is** the ledger reading.
