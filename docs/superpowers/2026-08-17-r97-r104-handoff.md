## What the measurements changed

### M-A — the handoff's named first action (`tab:BaseFactShape`)

It gets **8 focus nodes**, but only after `analyze(rep)`, which the membrane never sees.
`_validate` ran **once** during `compile_tables`, on 405 triples holding **0** `tab:BaseFact`.
`analyze(` appears in three test files and the demo notebook and **nowhere under `src/`**.

So R97's framing — *corpus gap or dead shape* — has a **third** answer for two of its four
shapes: a shape wired to a membrane that runs **before the facts it validates exist**. This is
a *phase* restriction, independent of R102's *gate* restriction, stacked on the same two call
sites. `tab:AggregationCellShape` and `tab:SectionTotalShape` stay unadjudicated at 0.

### M-B — R100's own cheap close, tested

R100 offered: *"a measured finding that no wired shape's liveness differs by leg except this
one, which would make the (shape, leg) key unnecessary."* **Measured across 34 wired shapes:
five differ.** The condition is not met and that escape route is closed.

Worse for the row's framing, **`dec:EscalationShape` does not differ by focus nodes at all**
(11–61 on every page call). It differs by criterion 2. The four that differ by focus nodes are
`dec:EventShape`, `dec:ExpansionRequestShape`, `tab:ContinuesColumnDisciplineShape`,
`tab:InLogicalColumnDisciplineShape` — and structurally so: their terms are written only at
`document.py:736-737` and `:1575`, so **no page graph can ever carry them**.

### The instrument's shape, sharpened by both

Not *"is this shape idle?"* but *"what does this check see?"*, and the key has turned out to
have **at least four axes**, three of them measured this session:

- **gate** — the tab-fact condition on both `_validate` sites (R102: 316 of 769 holons).
- **phase** — before/after `analyze()` (M-A, new this session).
- **leg** — page vs document scope (R100/M-B: five shapes).
- **graph set** — the registry measures 7 final `rep.graph`s; the document membrane validates
  only **4** of them (M-B). The guard's scope and the membrane's scope were never the same
  object, and nothing said so.

R101 adds a fifth notation (CI job × test module) and R103 a sixth (ontology file × membrane).

### M-C — R101's enumeration, delivered

45 files / 390 collected tests sit behind module-scope guards (of 1227 collected). **Nothing is
accidental today** in R101's sense. R101's own "48 modules / 8 `pytestmark`" figures are
**verified correct**, and 37 of the 48 evaluate at import time — the collapsing construct is
**77% of the surface**, not a minority pattern.

Three things the row could not have said:

1. **`tests/etkl/test_datagrid.py` is R101's failure in a costume the row does not describe.**
   Seven `@pytest.mark.skipif(pytest.importorskip("reportlab") is None, …)` decorators read as
   guarding 7 tests; measured, they collapse **59 → 1 skip line**, because decorators evaluate
   at import time. Additionally the `skipif` half is **dead code** — `importorskip(...) is None`
   is always `False` on success — so the only live behaviour is the opposite of what it reads as.
2. **`pytestmark = skipif` stays proportional; import-time `importorskip` collapses.** Any
   registry must record *which construct*, since only one is invisible in the CI summary.
3. **`rapidocr`'s exclusion is inferred, never written down** — and that is precisely the
   evidence that was available for `pandas` before R101, where it was wrong.
