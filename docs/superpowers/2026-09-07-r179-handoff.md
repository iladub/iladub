### 5b. PROPOSED — [[R180]]: decide whether a label carrying nothing is a reading

Raised by this loop. `span.build_reading` mints `HeaderNode(0, (flank,), "", None)` for a column

**The prediction, and it is the falsifiable part:** that deleting the emission is a *reading* change,
not a tidy-up — because `reshape.py:29` reads `tab:hasLabel`, and `reshape` is the round-trip oracle

**And the trap that makes this NOT cheap to dispose:** the filler's corpus population is **zero** —
`total bbox-less LabelCells: 0` across all 27 pages, both runs. A corpus diff will come back

R180 needs a synthetic fixture that forces the flank path, or the run will look like a pass and
prove nothing. See [[R171]] for the same hazard already recorded at a different site.

### What NOT to do

- **Do not add a shape to `vocab/shapes/tab-physical-shapes.ttl` and stop there.** `compile.py:556`
  loads the whole file for final validation, but `region_tiles` validates against a CBD subset of
  the IRIs named in `tiling._PHYSICAL_SHAPE_IRIS` (`src/iladub/etkl/tiling.py:45`). A shape in the
  file only lets a violating region **pass the gate and crash at final validation** — the R19 lesson
  recorded in that file's own comment. Falsification **F3** is the proof this is invisible without a
  gate test: with the shape in the file and out of the list, the file-level negative test
  `test_label_missing_box_leak_fails` **still passes**.
- **Do not treat the corpus diff as this loop's disposal.** It was what the residue prescribed and
  what R177's handoff prescribed, and it returned **WHOLE-FILE IDENTICAL on a shape that was
  defective** — twice, before and after the repair. It cannot see a closure-sensitivity defect,
  because `compile` runs only one of the two closures. Run the suite.
- **Do not add a SHACL shape without asking what it does under FULL RDFS closure.** `tab:hasLabel`
  has `rdfs:range tab:LabelCell` and `rowgroups.py:93` points it at an `EntryCell`; under a closure
  that materialises range typing, that entry *is* a label. `membrane.subclass_closure`'s docstring
  names this as the R19 accident, and `test_closure_equiv.py` is the oracle that catches it.
- **Do not compare corpus probe runs by grepping `^page N`** — every document has a page N. Carried
  forward from R177's handoff, and this loop used the whole-file diff instead.
- **Do not read "it only adds a shape" as "it cannot move a reading."** It can, and that is why O1
  exists: the shape runs inside `region_tiles`, so it is a gate on what may assert at all.
- **Do not tighten `tab:LabelCellPhysicalShape` to an unconditional `sh:minCount 1` without doing
  R180 first.** Falsification **F4** measures the cost: dropping the non-empty-text guard fails the
  flank-filler exemption **and both conformant examples**.
- **Do not pre-fill a suite figure in a spec's results table.** This loop wrote an O5 line with a
  plausible number in it before the run finished and had to strike it; the figure in § 4.1 is the
  one the run actually printed. A predicted number in a results table is indistinguishable from a
  measured one to the next reader.
- **Do not close a residue by striking its id in the INDEX.** The index cell is the bare id; the
  strike and the `(n/m closed)` snapshot belong on the **detail** row only
  (`tests/test_residue_register_integrity.py` parses `^\| *(R\d+) *\|`).
- **Do not verify a register change with `tests/etkl/` alone.** Run
  `tests/test_residue_register_integrity.py tests/test_doc_governance.py tests/test_arc_manifest.py
  tests/test_source_citations.py` — 45 tests, ~42 s.
- **And do not treat THAT list as sufficient either — this loop did, and CI went red.** Committing a
  new tracked `.ttl` bumps a hard-coded population count in **two more** modules,
  `tests/test_artifact_terms.py` and `tests/test_artifact_declarations.py` (146 → 147 here), and
  both are outside the four above. The trap is documented in those tests' own comments and is worth
  repeating: *the population is `git ls-files`, so a new `.ttl` joins it at `git add`, not at
  creation* — a full local suite run against an uncommitted tree is **green on a count that fails
  the moment the file is staged**. The honest pre-push run for a change that adds a tracked `.ttl`
  is `pytest tests/ --ignore=tests/etkl` (603 passed, 5 skipped, ~14 min), which is also roughly
  what CI runs.
