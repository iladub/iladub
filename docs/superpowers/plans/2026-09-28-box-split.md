# Box split — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a band holding ≥ 2 closed ruled boxes is split into one band per box, plus a residue band,
before `segment`. cbh `#table9` then compiles as the two tables the author drew.

**Architecture:** a new module reads the author's closed boxes: a PROCEDURAL rule reader, then
touch, frame and title-bar arithmetic. An AXIOM SPARQL query decides which bands hold ≥ 2 boxes.
`compile.page_bands` partitions those bands word by word and builds each box band with the
**unchanged** `_build_ruled_band`, fed box-scoped rules, hrules and chars.

**Tech Stack:** Python 3, pdfplumber, rdflib (SPARQL), reportlab (fixtures), pytest.

**Spec:** `docs/superpowers/specs/2026-09-28-box-split-design.md` (approved 2026-09-28, PR #284).
Cite it by § and do not re-derive it (CLAUDE.md § Plan authoring, rule 6).

**Doc impact: none.**

**This plan is a contract, not code (CLAUDE.md § Plan authoring discipline, rules 1–7).** It
states signatures, invariants, the seam to measure, and the falsifying oracle. **No function body
appears here.** Tests are specified by their assertions. The implementer writes them and proves
each one with a `## FALSIFICATION` block. **A task report without one fails review.**

## Global Constraints

- **CLAUDE.md § 8 gate.** No tuned constant and no tolerance. The only bound in this loop is the
  stroke width of the two marks being compared (spec § 0, R-c). Zero-width rules touch only at
  gap 0.
- **Classification** is spec § 6, verbatim. Every new function's docstring states its class and,
  for PROCEDURAL, why it is irreducible.
- `_build_ruled_band` (`src/iladub/etkl/compile.py`, `def _build_ruled_band`) is **not modified**.
- `geometry.extract_rules` / `extract_hrules` are **not modified** and **not called** for box bands.
- **The corpus is gitignored.** CI skips `-m corpus`, so **green CI is not evidence** for O2, C1,
  C2 or C3. Run them locally.
- **Local runs:**
  - **One test file per process**, launched from a `.sh` under `bash` (zsh leaves the args
    unsplit, which gives a phantom green).
  - **Full-corpus compiles are serial**, never two at once (memory kills recorded).
  - The suite runs in ~8-file chunks.
  - macOS has no `timeout`.
- **`git add` before running any gate.** Gates read tracked files.
- **The ink score is never an oracle** (spec § 5). Record it before and after as a fact only.

## Review Focus

1. **A band where one box's words spill past its frame** (a word straddling the outer rule). The
   partition must not duplicate the word or drop it. Every band word lands in exactly one output
   band. Owned by Task 3 (invariant I-3a).
2. **A box whose title bar holds no words**, or a band with **no title bars at all**. The split
   still happens and captions are empty, not an error. Owned by Task 3.
3. **Two closed boxes stacked vertically in one band** (not side by side). R-d fires on them too.
   The `(top, x0)` order must put the upper box first. Owned by Task 3.
4. **A page with no rules at all.** The box reader returns `[]` and `page_bands` does no extra
   work beyond computing that. Owned by Task 1 (empty-page test) and Task 3 (unchanged band list).
5. **Section repair naming a split band's original index.** Box bands carry `specs = None` (spec
   § 3.6), so a `section_repair_bands` entry pointing at them must not rebuild them. Owned by
   Task 3.

### Task 1: The box reader — `boxes.py`

**Files:** create `src/iladub/etkl/boxes.py` and `tests/etkl/test_boxes.py`; modify
`tests/etkl/fixtures.py`.

**Interfaces — Produces:**

```
@dataclass(frozen=True) class BoxRule:  orient: str ("H"|"V"); x0, x1, top, bottom: float   # painted extent
@dataclass(frozen=True) class Box:      x0, x1, top, bottom: float
                                        verticals: tuple[BoxRule, ...]; horizontals: tuple[BoxRule, ...]
                                        title_bar: tuple[float, float, float, float] | None   # (x0, x1, top, bottom)
def extract_box_rules(pdf_path: str, page_number: int = 0) -> list[BoxRule]
def touches(h: BoxRule, v: BoxRule) -> bool
def closed_boxes(rules: Sequence[BoxRule], fills: Sequence[...]) -> list[Box]     # fills: see Step 0
def page_boxes(pdf_path: str, page_number: int = 0) -> list[Box]                  # the composition
```

**Invariants:**

- **I-1a** `extract_box_rules` implements spec § 2.1 exactly. A non-square **black**-filled rect is
  a rule. **Each edge** of a stroked rect is a rule. A stroked line is a rule. Every rule is at its
  **painted** extent (± half the linewidth).
- **I-1b** `touches` is spec § 2.2: `x-gap ≤ t` and `y-gap ≤ t`, where
  `t = min(thickness_h, thickness_v)`. Nothing else enters.
- **I-1c** A `Box` is spec § 2.3: a touch-graph component with ≥ 2 H, ≥ 2 V, and a closed frame.
  The frame's side coverage counts the **perpendicular rules' painted extent** too. Spec § 7.2
  records the failure of a check that did not.
- **I-1d** `title_bar` is spec § 2.4: a non-black fill whose bottom touches the top rule
  (I-1b's bound, with the fill's own extent as the other mark) and whose x-extent lies within the
  outer verticals. Otherwise `None`.

**Seams to MEASURE before writing code:**

- **Step 0a:** read `internal/benchmarks/cbh-boxes-2026-09-28/boxes.py` (`rules_of`, `boxes_of`)
  and `closed2.py` as **measurement references**, not code to copy. Re-run
  `TOUCH=stroke .venv/bin/python internal/benchmarks/cbh-boxes-2026-09-28/boxes.py
  corpus/ag-trade/cbh-stem-2026-08-03.pdf 0`. It must print a box
  `bbox [543.41, 690.43, 689.64, 722.28], cols 2, rows 4, tiled 21/21`. If it doesn't, stop: the
  spec's § 7 no longer describes the tree.
- **Step 0b:** decide how title-bar fills reach `closed_boxes`. The probe reads them off
  `page.rects`. Whatever you choose, `page_boxes` is the only caller that touches pdfplumber

**Invariants:**

  call. Literals are emitted canonically. A band with no boxes emits nothing.

### Task 3: The split, wired into `page_bands`

**Files:** modify `src/iladub/etkl/boxsplit.py` and `src/iladub/etkl/compile.py` (`def page_bands`,
the `for band in raw_bands:` loop); extend `tests/etkl/test_boxsplit.py`.

**Interfaces — Produces:**

```
def split_band(band: Band, boxes: Sequence[Box], page_chars: Sequence[Char],
               pdf_path: str, page_number: int) -> list[tuple[Band, tuple | None]]
      # (built band, specs entry). Box bands carry None; residue sub-bands carry what the
      # existing path would have produced for them.
```

**Invariants** (spec § 3.3–3.6, cited, not re-derived):

- **I-3a Partition.** Every word of `band` lands in exactly one output: a box band's lines, a box
  band's captions (its title-bar words), or the residue. Test it as a multiset equality over
  `(text, x0, top)`.
- **I-3b Box scoping** (spec § 3.4). Each box band is built by `_build_ruled_band` with:
  - `sub_rules` = the box's own verticals as `geometry.Rule(x=(x0+x1)/2, top, bottom)`;
  - `sub_hrules` = the box's own horizontals as `geometry.HRule`;
  - `page_chars` clipped to the box's x-extent **and** y-extent.

  No page-wide rule list is consulted.
- **I-3c Captions after the build** (spec § 3.5): `captions = title_lines + built.captions`.
- **I-3d Residue.** Words in no box and no title bar form **one** `Band`. It goes through
  `cut_trailing_notes(segment(residue), pdf_path, page_number)` and the **existing** per-sub-band
  code (ruled or unruled), exactly as a raw band does today. No residue logic is duplicated: factor
  the loop body into a local helper if needed, **without** changing its behaviour for non-split
  bands.
- **I-3e Order.** The output is ordered by `(top, x0)` of each band.
- **I-3f** A band `bands_to_split` does not select takes the **unchanged** path. The N1 and N2
  fixtures, and every Task 0 C2 document other than cbh, must produce byte-identical `page_bands`
  output.

**Seams to MEASURE before writing the call:**

- **Step 0a:** `page_bands` builds `specs` in parallel with `bands`, and later rebuilds a named
  band with `section_repair=True`. **MEASURE** every reader of `specs` below the loop
  (`grep -n "specs" src/iladub/etkl/compile.py`). Confirm that a `None` entry means "never
  rebuilt" at each one. If any reader indexes `specs` assuming one entry per `segment` output, say
  so in the task report.
- **Step 0b:** `_build_ruled_band`'s `band_chars` filter is by y only (spec § 7.3). **MEASURE**
  that clipping `page_chars` before the call is sufficient: no other char source is read inside it

- **Step 0c:** `absorb_unit_markers` and `merge_run_candidates` run on the full list after the
  loop. Spec § 7.3 measured `merge_run_candidates → ()` with the split. Re-measure on the built
  tree, not the what-if.
