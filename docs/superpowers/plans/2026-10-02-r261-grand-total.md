# R261 loop (b) — the grand total — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Serves:** prog:criterion:etkl:03 — loop (b) of the [[R261]] totals family: cbh p0's `1,951,264`.

**Goal:** a lone number binds as a `tab:PrintedTotal` aggregating the page's table-level
PrintedTotals when their exact `Decimal` sum equals it **and** `AskTotalRole` answers
`total_of_totals` on the derived crop; R7 carries it into the document graph.

**Architecture:** a second level inside `compile._bind_printed_totals`, beside the table level and
not gated by its guard. A new worker module `totalrole.py` mirrors `printedtotal.py`'s reader stack.
`tab:PrintedTotalShape` gains one two-halved constraint. `document._printed_total_bands` follows
`tab:aggregates` one hop.

**Tech Stack:** Python 3, rdflib, pySHACL, pdfplumber, BAML (Haiku 4.5 via the `Claude` client),
pytest.

**Spec:** `docs/superpowers/specs/2026-10-02-r261-grand-total-design.md` (approved 2026-10-02,
PR #292 addendum `981c80d`). It extends `specs/2026-10-01-r261-totals-family-design.md`. Cite both
by §; do not re-derive them (CLAUDE.md § Plan authoring, rule 6). Rulings R-a…R-h (spec § 0) are
not re-opened.

**Doc impact: none** (this plan; the spec declares the increment).

**This plan is a contract, not code** (CLAUDE.md § Plan authoring, rules 1–7): signatures,

## Decisions this plan takes where the spec is silent (reversible — review them)

- **D1 Operand table band = the unique `j` with `reports[j].table_uri == t`** for the operand's
  `tab:totalOf` table `t` (N3). Zero or several such `j` ⇒ the crop cannot be built ⇒ **no claim**:
  the worker is not asked and nothing is recorded (mirrors ruling R3). Task 0 measures it on cbh r2
  and the fixture.
- **D2 Signature.** `_bind_printed_totals(pdf_path, page_number, doc, idx, band, bands, reports,
  graph, brec)`; the table level derives `table_band`/`prev_report` from `bands[idx-1]` /
  `reports[-1]` exactly as the call site does today. Return type unchanged.
- **D3 Per line, in order:** table level, then — only if the table level did not **bind** that
  line — the totals level (spec § 2 step 1, read literally). A line the table level recorded
  `not_total` may still be tried at the totals level; each level records its own decision.
  Operands are read from `graph` **at that line**, so a total bound on an earlier line of the same
  band is an operand of a later line (Review Focus 1).
- **D4 Listing** = spec § 3's (each operand table band's lines, then that operand's `tab:cellText`,
  in operand order) **plus the candidate band's lines before `line_no`, then the candidate line** —
  the same fix `printedtotal.listing_of` carries (N7). Identical to the spec's listing on cbh
  (line 0).
- **D5 A closed non-binding answer** (`table_total`/`other`/`cannot_tell`) records `printed_total`
  chosen `not_total`; no claim records nothing — the table level's semantics (N7, ruling R3).
- **D6 Operand order** = ascending band index of the operand PrintedTotal (its URI's `idx`), so the
  listing, the rationale and `tab:aggregates` are deterministic.

## Review Focus

1. **A grand total printed directly beneath the last table total, in the same band** (D3): the
   earlier line binds at table level first and is then an operand of the later one. A reader
   expects it to bind. Owned by Task 4.
2. **An operand whose table band cannot be resolved uniquely** (D1): no ask, no record, no bind —
   never a crop guessed from `j − 1`. Owned by Task 4 (unit test on the resolver).
3. **The totals-level reader gives no claim** (absent, raises, out-of-set, None): nothing recorded,
   nothing bound, the band read as today. Owned by Task 4.
4. **A lone number after the grand total equal to the sum of the table totals plus the grand total**
   (R-f): never matches, never asked. Owned by Task 4.
5. **A recording replayed against a different page whose operand tables moved by one word**: the key
   moves, so the replay misses and is no claim (D4). Owned by Task 3.
